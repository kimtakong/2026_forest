### 5-1. 문제: 데이터의 동 목록은 구마다 시점이 다르다

admdongkor의 시점별 행정동 색인(1975~2025)과 비교했다. 25개 구 모두 데이터의 동 목록이 **어느 한 시점의 목록과 100% 일치**했다(Jaccard 1.0). 그런데 그 시점이 구마다 다르다.

| 구 | 데이터 동 목록이 일치하는 시점 | 바뀐 점 |
|---|---|---|
| 동대문구 | **2008-12-31** | 2009년 22개 동 → 14개 동으로 통폐합하기 전 |
| 노원구 | 2010-12-31 | 공릉1·3동 → 공릉1동 |
| 종로구 | 2011-12-31 | 명륜3가동 → 혜화동에 통합 |
| 중구 | 2012-12-31 | 신당1·2·3·4·6동 → 신당·다산·약수·청구·동화동 |
| 송파구 | 2014-12-31 | 위례동 신설 전 |
| 구로구 | 2019-12-31 | 항동 신설 전 |
| 강동구 | 2021-04-01 | 상일동 → 상일제1동, 강일동 일부 → 상일제2동 |
| 강남구 | 2022-10-01 | 일원2동 → 개포3동 |
| 나머지 17개 구 | 2025-12-31 | — |

**이름만으로 맞추면 틀린다.** 예를 들어 데이터의 "전농제2동"(2008년 단위)은 면적의 98.9%가 현재 **전농1동**에 있다. 그런데 이름은 현재 전농2동과 같다. "이문제2동"도 95.1%가 현재 이문1동에 있다.

### 5-2. 방법: 시점 경계를 면적으로 겹쳐 대응시킨다

1. 구마다 데이터 동 목록과 가장 잘 맞는 시점의 경계 폴리곤을 쓴다.
2. 그 폴리곤을 2025-12-31 경계와 겹친다. 가장 많이 겹치는 현재 동을 1차 대응으로 둔다.
3. 어떤 데이터 동에도 대응되지 않은 현재 동(신설·분할로 생긴 동)은 가장 많이 덮는 데이터 동의 단위에 합친다.
   - 예: 상일제2동은 면적 100%가 옛 강일동 안에 있으므로 강일동 단위에 합친다.
4. 서로 연결된 데이터 동·현재 동 묶음 하나가 **지도 단위** 하나다. 단위 경계는 현재 동 경계를 합친 것이다.
