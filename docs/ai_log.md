# AI 사용 기록

형식: `날짜 | 도구 | 작업 범위 | 핵심 프롬프트 요지 | 사람이 검증한 내용`

## AI 이용 조건 (공모전 「AI 활용」 준수사항)

- **입력한 자료(3항):** 분석 과정에서 AI에 입력한 자료는 공공데이터포털에 공개된 서울시설공단 자료(이용허락범위 제한 없음)와 그 집계 결과, 이 저장소의 코드뿐이다.
  - 탑승내역에는 이름·연락처 같은 개인식별정보가 없다.
  - 개인정보·개인위치정보·영업비밀·비공개 자료는 입력하지 않았다.
- **서비스 이용 조건(4항):** Anthropic의 이용약관과 개인정보 처리방침에서 입력 데이터의 보관, 모델 학습 활용, 제3자 제공 조건을 확인했다.
  - 입력한 자료는 누구나 내려받을 수 있는 공개 자료다. 그래서 학습에 쓰이더라도 공개 범위가 넓어지지 않는다.
- **결과 확인(5항):** 결과를 재현하고 확인하는 데 AI 서비스는 필요 없다(README "AI 사용" 절).
- **검증(2항):** 아래 표의 마지막 열은 참가자가 직접 확인한 내용이다.
  - Claude Code 작업은 "코드 — 정의대로 구현됐는지 검토한 부분 / 결과 — 대조한 산출물과 숫자"로 적었다.
  - 대조한 산출물은 모두 `outputs/tables/`에 있다.
